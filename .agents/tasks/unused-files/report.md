# Unused Files Investigation Report

**Project:** INDI Ouro 2.0 — `c:\Users\User\Desktop\Projetos\INDI Ouro 2.0`  
**Method:** `npx unimported` (initial sweep) + manual grep cross-reference on all candidates  
**Scope:** `src/` only. `node_modules/`, `.next/`, `public/` excluded.  
**Date:** 2025

---

## Summary

`npx unimported` flagged 513 files as unused. After filtering out all Next.js framework-reserved files (`layout.tsx`, `page.tsx`, `loading.tsx`, `not-found.tsx`, `route.ts`, `page.test.tsx`) and cross-referencing every remaining candidate with `grep` across the full `src/` tree, **20 confirmed dead files** were identified.

They fall into four clusters:
1. **Old shadcn scaffold** — components generated by `shadcn init` that were never wired up.
2. **Old calendar components** — replaced by the `features/agenda/` system; the entire `src/components/calendar/` folder is orphaned.
3. **Old PDF/export utils** — superseded by `src/lib/pdf/` generators; the old `src/utils/` entries are never imported.
4. **Orphaned constants/helpers** — navigation link arrays and utility modules that have no consumer.
